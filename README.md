# 🛒 쇼핑 리스트

아이템 추가 · 수정 · 삭제 · 체크 기능이 있는 간단한 Streamlit 쇼핑 리스트 앱입니다.
요구사항은 [PRD.md](PRD.md)를 참고하세요.

## 설치

```bash
pip install -r requirements.txt
```

## 실행

```bash
streamlit run app.py
```

브라우저에서 http://localhost:8501 이 열립니다.

## 배포

GitHub에 올린 뒤 [Streamlit Community Cloud](https://share.streamlit.io)에서 저장소와 `app.py`를 선택해 배포합니다.
